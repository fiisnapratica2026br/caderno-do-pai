# VIDA DE COTISTA — PILOTO V2

Esta pasta contém a nova linha de produção do piloto **Cadê o aluguel?**.

O Piloto V1 com SadTalker foi preservado em `experimentos/vida-de-cotista-piloto/` como histórico técnico. Ele não é mais a rota recomendada porque o resultado visual ficou artificial.

## Meta do V2

Produzir uma micronovela vertical de 45–60 segundos que pareça cena, não avatar.

Prioridades:
1. naturalidade
2. consistência dos personagens
3. clareza narrativa
4. veracidade financeira
5. custo

## Regra de produção

Antes de qualquer lote:
1. fechar roteiro
2. selecionar a referência oficial
3. gerar UM teste de 3–5 segundos
4. avaliar movimento, olhos, cabeça, tronco, boca e identidade
5. só seguir se a naturalidade for aceitável

## Teste V2 escolhido

Marcelo:
> “Pera aí... como assim o aluguel não entrou?”

Essa fala é curta, emocional e suficiente para comparar técnicas.
